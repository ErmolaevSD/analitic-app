# 🚀 ИНСТРУКЦИЯ ПО СОЗДАНИЮ И ЗАПУСКУ JAR НА WINDOWS

## 📋 ТРЕБОВАНИЯ

Для запуска приложения на Windows нужно:

1. **Java 21 или выше** (установлена и добавлена в PATH)
   - Проверка: откройте CMD и выполните `java -version`
   - Если не установлена: скачайте с [oracle.com](https://www.oracle.com/java/technologies/downloads/#java21)

2. **Maven** (опционально, если вы хотите собрать JAR самостоятельно)
   - Скачать: [maven.apache.org](https://maven.apache.org/download.cgi)

---

## 🔨 СПОСОБ 1: СБОРКА JAR САМОСТОЯТЕЛЬНО (рекомендуется)

### Шаг 1: Откройте Command Prompt (CMD)

### Шаг 2: Перейдите в директорию проекта

```cmd
cd C:\Users\<ВашИмя>\IdeaProjects\analitic-app
```

### Шаг 3: Выполните сборку

```cmd
mvn clean package -DskipTests
```

**Это займет 2-3 минуты**

### Шаг 4: Найдите созданный JAR файл

```cmd
dir target\*.jar
```

Должен появиться файл: `analitic-1.0-SNAPSHOT.jar` или похожий на него

---

## 🎯 СПОСОБ 2: ИСПОЛЬЗОВАНИЕ ГОТОВОГО JAR

Если JAR уже создан, выполните:

### Способ 2a: Запуск из CMD

```cmd
java -jar analitic-1.0-SNAPSHOT.jar
```

### Способ 2b: Создание BAT файла для удобного запуска

1. Создайте файл `run.bat` в директории с JAR файлом:

```batch
@echo off
echo Starting Analitic App...
java -jar analitic-1.0-SNAPSHOT.jar
pause
```

2. Сохраните файл

3. **Дважды кликните** на `run.bat` - приложение запустится

## 🖥️ ЗАПУСК НА WINDOWS (ПОДРОБНАЯ ИНСТРУКЦИЯ)

### Вариант 1: Запуск через CMD

1. **Откройте Command Prompt:**
   - Нажмите `Win + R`
   - Введите `cmd`
   - Нажмите Enter

2. **Перейдите в папку с JAR:**
   ```cmd
   cd C:\путь\к\analitic-app\target
   ```

3. **Запустите приложение:**
   ```cmd
   java -jar analitic-1.0-SNAPSHOT.jar
   ```

4. **Приложение запустится в отдельном окне**

### Вариант 2: Запуск через BAT файл (самый удобный)

1. **Создайте файл `run.bat` рядом с JAR файлом:**

```batch
@echo off
REM Запуск приложения Analitic App
REM Убедитесь что Java установлена и добавлена в PATH

echo.
echo ================================
echo   Запуск Analitic App
echo ================================
echo.

java -jar analitic-1.0-SNAPSHOT.jar

if %errorlevel% neq 0 (
    echo.
    echo ERROR: Не удалось запустить приложение
    echo Убедитесь что Java установлена: java -version
    echo.
    pause
)
```

2. **Сохраните файл с расширением .bat**

3. **Дважды кликните на файл для запуска**

### Вариант 3: Создание ярлыка (самый удобный для конечного пользователя)

1. **Создайте файл `run.bat`** (как выше)

2. **Создайте ярлык:**
   - Правый клик на `run.bat`
   - "Отправить" → "Рабочий стол (создать ярлык)"

3. **Отредактируйте ярлык (опционально):**
   - Правый клик → "Свойства"
   - "Аванпост" → "Другой значок" (выберите красивый значок)

4. **Теперь можно запускать двойным кликом с рабочего стола**

## 🔧 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: "Java не найдена"

**Решение:**
```cmd
# Проверьте установку Java
java -version

# Если не работает - добавьте Java в PATH:
# 1. Откройте "Переменные среды"
# 2. Найдите JAVA_HOME или PATH
# 3. Добавьте путь к Java (C:\Program Files\Java\jdk-21\bin)
```

### Проблема: "JAR файл не найден"

**Решение:**
```cmd
# Убедитесь что вы в правильной директории
dir
# Должен быть файл analitic-1.0-SNAPSHOT.jar

# Если файла нет - соберите его заново
mvn clean package -DskipTests
```

### Проблема: "Port already in use" (если приложение использует порт)

**Решение:**
```cmd
# Закройте другие окна приложения или перезагрузитесь
```

## 🚀 ОПТИМАЛЬНАЯ КОМАНДА ДЛЯ ЗАПУСКА

Для запуска с оптимальными параметрами памяти:

```cmd
java -Xmx1024m -Xms512m -jar analitic-1.0-SNAPSHOT.jar
```

Параметры:
- `-Xmx1024m` - Максимум памяти: 1 GB
- `-Xms512m` - Начальная память: 512 MB
