# Analitic App

![Java](https://img.shields.io/badge/language-Java-blue)

## Описание

**Analitic App** — десктопное Java-приложение для аналитики и проверки административных данных. Оно выполняет автоматическую сверку Excel файлов, выявляет дубликаты и проблемные временные периоды в оборотах административных правонарушений. Программа предназначена для офицеров и специалистов МВД, работающих с массивами административных записей.

## Основные возможности

- **Импорт и анализ административных данных** (формат Excel)
- **Автоматический поиск дубликатов** в одном или двух файлах
- **Выявление проблемных периодов** (разрывы между правонарушениями по ст. 116)
- **Экспорт аналитических результатов** в новые Excel файлы
- **Удобный графический интерфейс** (JavaFX)

## Архитектура

- **JavaFX UI** — main-view.fxml, MainController
- **Сервисный слой** — MainService: бизнес-логика, аналитика, экспорт
- **Менеджеры файлов** — ExcelFileManager, TXTFileManager: операции импорта/экспорта
- **Валидация и обработка ошибок** — ручное и автоматизированное логирование

## Сценарии использования

- Выберите Excel-файл и запустите анализ на дубликаты или сверку периодов.
- Получите экспорт файлов с результатами (дубликаты, уникальные записи, проблемные периоды).
- Просмотрите подробный лог операций в приложении.

## Установка и запуск

1. Требуется Java 17+ (или совместимая)
2. Склонируйте репозиторий:
    ```sh
    git clone https://github.com/ErmolaevSD/analitic-app.git
    ```
3. Соберите и запустите приложение:
    ```sh
    ./gradlew build
    java -jar build/libs/analitic-app.jar
    ```
